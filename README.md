# Prueba de Despliegue en Railway

Este es un proyecto sencillo de Node.js con Express para probar el flujo de despliegue en [Railway](https://railway.app/).

## Cómo ejecutar localmente

1. Instala las dependencias:
   ```bash
   npm install
   ```
2. Inicia el servidor:
   ```bash
   npm start
   ```
